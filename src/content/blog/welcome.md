# Welcome to Demo App

This is your first blog post, managed entirely through **Decap CMS**.

## What You Can Do

- ✍️ Write and edit blog posts from the **Admin Panel** at `/admin`
- 🖼️ Upload and manage media files
- 📄 Manage site pages and settings
- 🚀 Auto-deploy via GitHub on every save

## Getting Started

Visit [/demo-app/admin](/demo-app/admin) to open the CMS dashboard. Sign in with your **GitHub account** to start creating content.

Every time you publish a post or make a change in the CMS, it commits directly to your GitHub repository and triggers a new deployment.

## Built With

- **Astro** — blazing fast static site generator
- **Decap CMS** — Git-based content management
- **GitHub** — version control & deployment
